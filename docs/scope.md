# VideoHub MVP 范围文档

> 基于 [PRD v1.1](./prd.md) 第 9 节 M1 里程碑，定义最小可用产品的功能边界与验收标准。

---

## 1. MVP 目标

用最小工作量交付一个可用的视频管理平台：用户打开浏览器即可上传、浏览、播放、下载和删除服务器上的视频文件，手机端同样可用。

---

## 2. 功能范围

### 2.1 包含（In Scope）

| # | 功能 | 说明 |
|---|------|------|
| 1 | 视频上传 | 点击选择文件上传，显示进度条；支持填写标题（默认取文件名）；支持大文件分片上传和断点续传；上传完成后探测元信息（时长、分辨率、编码、大小） |
| 2 | 视频缩略图 | 上传完成后 FFmpeg 自动截取视频画面生成缩略图 |
| 3 | 视频列表 | 网格卡片展示所有视频（缩略图、标题、时长、大小、上传时间）；按上传时间倒序；分页，每页 20 条 |
| 4 | 视频播放 | HTML5 播放器播放 MP4(H.264) 文件；支持播放/暂停、进度拖拽、音量、全屏；支持 HTTP Range 拖拽跳转；播放进度记忆（localStorage），下次打开自动续播 |
| 5 | 视频下载 | 下载原始文件，保持原格式画质；支持 HTTP Range 断点续传 |
| 6 | 视频删除 | 点击删除按钮，二次确认后删除；同步清理服务器文件、缩略图和数据库记录 |
| 7 | 响应式布局 | 手机 / 平板 / 桌面三档适配；手机端所有核心功能可用 |

### 2.2 不包含（Out of Scope — 后续迭代）

| 功能 | 归属阶段 |
|------|---------|
| 拖拽上传 | M2 |
| 播放速度调节 | M2 |
| 搜索与排序 | M2 |
| 视图切换（网格/列表） | M2 |
| 非 MP4 格式实时转码播放 | M3 |

## 3. 页面清单

| 页面 | 路由 | 说明 |
|------|------|------|
| 首页 | `/` | 视频卡片网格 + 分页器 |
| 上传页 | `/upload` | 文件选择 + 标题输入 + 进度条 |
| 播放页 | `/video/:id` | 播放器 + 视频信息 + 下载按钮 + 删除按钮 |

---

## 4. API 清单

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/videos` | 视频列表，支持 `page` / `pageSize` 参数 |
| GET | `/api/videos/:id` | 视频详情 |
| POST | `/api/videos/upload` | 小文件整体上传（multipart/form-data） |
| DELETE | `/api/videos/:id` | 删除视频 |
| POST | `/api/videos/upload/chunk` | 分片上传（单个分片） |
| POST | `/api/videos/upload/merge` | 合并已上传分片 |
| GET | `/api/videos/:id/stream` | 视频流播放（支持 Range） |
| GET | `/api/videos/:id/download` | 视频下载（Content-Disposition: attachment） |
| GET | `/api/videos/:id/thumbnail` | 获取视频缩略图 |

## 5. 数据模型

### videos 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增主键 |
| title | VARCHAR(255) | 视频标题 |
| filename | VARCHAR(255) | 原始文件名 |
| storage_path | VARCHAR(500) | 服务器存储路径 |
| thumbnail_path | VARCHAR(500) | 缩略图路径（上传后 FFmpeg 自动生成） |
| mime_type | VARCHAR(50) | MIME 类型 |
| file_size | BIGINT | 文件大小（字节） |
| duration | FLOAT | 时长（秒） |
| resolution | VARCHAR(20) | 分辨率（如 1920x1080） |
| codec | VARCHAR(50) | 编码格式 |
| created_at | DATETIME | 上传时间 |

## 7. 验收标准

### 7.1 视频上传

- [ ] 可选择本地视频文件（MP4、MKV、AVI、MOV、WMV、FLV、WebM）上传
- [ ] 非视频文件被拦截（MIME + 扩展名双校验）
- [ ] 小文件（< 100MB）整体上传，大文件自动切换为分片上传
- [ ] 上传过程中显示进度百分比
- [ ] 上传中断后重新上传，已完成的分片无需重传（断点续传）
- [ ] 上传完成后视频出现在首页列表中
- [ ] 视频元信息（时长、分辨率、编码、大小）正确入库

### 7.2 视频缩略图

- [ ] 上传完成后自动生成缩略图（截取视频第 1 秒画面）
- [ ] 缩略图格式为 JPG，保存至 `data/thumbs/`
- [ ] 视频列表卡片正确展示缩略图

### 7.3 视频列表

- [ ] 首页以卡片网格展示所有视频
- [ ] 每张卡片显示：缩略图、标题、时长、文件大小、上传时间
- [ ] 按上传时间倒序排列
- [ ] 超过 20 条时分页正常工作

### 7.4 视频播放

- [ ] 点击视频卡片进入播放页，MP4(H.264) 视频可正常播放
- [ ] 播放器支持：播放/暂停、进度拖拽、音量调节、全屏
- [ ] 拖拽进度条可跳转到任意位置（HTTP Range）
- [ ] 播放页显示视频标题、时长、分辨率、文件大小、上传时间
- [ ] 关闭/刷新页面后重新打开，自动从上次播放位置续播
- [ ] 播放进度存储在浏览器 localStorage 中

### 7.5 视频下载

- [ ] 播放页点击下载按钮，浏览器开始下载原始视频文件
- [ ] 下载文件与上传文件一致（格式、大小、内容）

### 7.6 视频删除

- [ ] 播放页点击删除按钮，弹出确认对话框
- [ ] 确认后视频从列表消失
- [ ] 服务器磁盘文件和缩略图同步删除

### 7.7 响应式

- [ ] 桌面端（> 1024px）布局正常
- [ ] 平板端（768px - 1024px）布局正常
- [ ] 手机端（< 768px）所有功能可正常操作
- [ ] 手机端播放器支持全屏
