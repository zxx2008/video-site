---

## 2. 产品概述

### 2.1 背景

用户在服务器上存储了大量视频文件，需要一种便捷的方式通过浏览器远程访问、播放和管理这些视频。现有方案（FTP/SMB 等）操作繁琐且不支持在线播放，因此需要一个轻量级的 Web 视频管理与播放平台。

### 2.2 目标用户

- 个人用户：在家庭服务器/NAS 上管理个人视频收藏
- 小型团队：内部视频资料的共享与播放

### 2.3 产品目标

1. 支持通过浏览器在线播放服务器端视频，无需下载
2. 支持视频上传与下载，方便资源管理
3. 所有人均可自由访问、上传和删除，无需登录
4. 响应式设计，确保手机端可正常使用所有核心功能
5. 内网部署，架构从简

## 3. 功能需求

### 3.1 视频上传

| 项目 | 说明 |
|------|------|
| 优先级 | P0 |
| 描述 | 用户将本地视频文件上传至服务器 |

**功能详情：**

- 支持格式：MP4、MKV、AVI、MOV、WMV、FLV、WebM
- 单文件大小限制：4GB
- 支持拖拽上传和点击选择上传
- 显示上传进度条（百分比 + 已传/总量）
- 支持大文件分片上传，断点续传
- 上传时可填写视频标题（默认使用文件名）
- 上传完成后自动生成视频缩略图
- 上传完成后服务端自动探测视频元信息（时长、分辨率、编码格式、文件大小）

### 3.2 视频列表

| 项目 | 说明 |
|------|------|
| 优先级 | P0 |
| 描述 | 展示所有已上传的视频 |

**功能详情：**

- 列表展示：缩略图、标题、时长、文件大小、上传时间
- 支持网格视图和列表视图切换
- 支持按上传时间、文件名、文件大小排序
- 支持按标题关键字搜索
- 分页加载，每页 20 条

### 3.3 视频删除

| 项目 | 说明 |
|------|------|
| 优先级 | P0 |
| 描述 | 任何人均可删除视频 |

**功能详情：**

- 删除前弹出二次确认对话框
- 删除后同步清理服务器文件和数据库记录

---

### 3.4 视频播放

#### 3.4.1 在线播放

| 项目 | 说明 |
|------|------|
| 优先级 | P0 |
| 描述 | 在浏览器中直接播放服务器端视频 |

**功能详情：**

- 使用 HTML5 Video 播放器
- 基础控制：播放/暂停、进度拖拽、音量调节、全屏
- 支持播放速度调节（0.5x / 1x / 1.5x / 2x）
- 支持 HTTP Range 请求，实现视频拖拽跳转（无需完整下载）
- 对于非 MP4(H.264) 格式，服务端实时转码为兼容格式流式输出
- 记忆播放位置（基于浏览器 localStorage），下次打开自动续播
- 手机端支持横屏全屏播放

#### 3.4.2 播放页信息

| 项目 | 说明 |
|------|------|
| 优先级 | P1 |
| 描述 | 播放页展示视频详细信息 |

**功能详情：**

- 显示：视频标题、时长、分辨率、文件大小、上传时间
- 下载按钮入口

---

### 3.5 视频下载

| 项目 | 说明 |
|------|------|
| 优先级 | P0 |
| 描述 | 用户将服务器端视频下载到本地 |

**功能详情：**

- 下载原始视频文件（保持原格式和画质）
- 支持 HTTP Range 断点续传下载
- 大文件通过浏览器原生下载机制处理

## 4. 非功能需求

### 4.1 响应式设计

- 采用移动端优先（Mobile First）的响应式布局
- 断点定义：
  - 手机：< 768px
  - 平板：768px - 1024px
  - 桌面：> 1024px
- 手机端核心功能完全可用：浏览、播放、上传、下载
- 触屏友好的交互控件（按钮尺寸 ≥ 44px）

### 4.2 性能要求

| 指标 | 目标值 |
|------|--------|
| 首页加载时间 | < 2s（桌面端） |
| 视频起播时间 | < 3s（局域网环境） |
| 上传速度 | 充分利用网络带宽，不低于带宽的 80% |
| 并发用户数 | ≥ 10（个人/小团队场景） |

### 4.3 安全要求

- 文件上传类型校验（MIME + 扩展名双校验），防止上传非视频文件

### 4.4 兼容性

| 平台 | 最低支持版本 |
|------|-------------|
| Chrome | 90+ |
| Firefox | 90+ |
| Safari | 14+ |
| Edge | 90+ |
| iOS Safari | 14+ |
| Android Chrome | 90+ |

## 5. 技术方案建议

| 层级 | 推荐技术 | 说明 |
|------|---------|------|
| 前端 | Vue 3 + Vite | 轻量、响应式友好，生态成熟 |
| UI 框架 | Tailwind CSS | 实用优先，响应式支持好 |
| 播放器 | Plyr / Video.js | 开源播放器，移动端兼容好 |
| 后端 | Node.js (Express/Fastify) 或 Go (Gin) | 适合文件 I/O 密集场景 |
| 数据库 | SQLite | 轻量部署，适合个人/小团队 |
| 文件存储 | 本地磁盘 | 服务器直接存储，路径映射 |
| 视频处理 | FFmpeg | 缩略图生成、元信息探测、转码 |

## 6. 页面结构

```
/                 — 首页（视频列表）
/upload           — 上传页
/video/:id        — 视频播放页
```

### 6.1 页面线框描述

**首页（视频列表）**
- 顶部导航栏：Logo、搜索框、上传按钮
- 排序与视图切换工具栏
- 视频卡片网格（缩略图 + 标题 + 时长 + 大小）
- 底部分页器

**视频播放页**
- 视频播放器区域（顶部，16:9 比例）
- 视频信息区域（标题、元数据）
- 下载按钮

**上传页**
- 拖拽上传区域
- 视频标题输入框
- 上传进度展示
- 上传历史列表

## 7. API 概要设计

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | /api/videos | 获取视频列表（分页、搜索、排序） |
| GET | /api/videos/:id | 获取单个视频详情 |
| POST | /api/videos/upload | 上传视频文件 |
| POST | /api/videos/upload/chunk | 分片上传 |
| DELETE | /api/videos/:id | 删除视频 |
| GET | /api/videos/:id/stream | 视频流播放（支持 Range） |
| GET | /api/videos/:id/download | 视频下载 |

## 8. 数据模型

### 8.1 视频表 (videos)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增主键 |
| title | VARCHAR(255) | 视频标题 |
| filename | VARCHAR(255) | 原始文件名 |
| storage_path | VARCHAR(500) | 服务器存储路径 |
| thumbnail_path | VARCHAR(500) | 缩略图路径 |
| mime_type | VARCHAR(50) | MIME 类型 |
| file_size | BIGINT | 文件大小（字节） |
| duration | FLOAT | 时长（秒） |
| resolution | VARCHAR(20) | 分辨率（如 1920x1080） |
| codec | VARCHAR(50) | 编码格式 |
| created_at | DATETIME | 上传时间 |

## 9. 里程碑规划

### M1 — 基础可用（MVP）

- 视频上传（分片上传 / 断点续传）
- 视频列表展示
- 视频缩略图自动生成
- 视频在线播放（MP4）
- 播放进度记忆（localStorage）
- 视频下载
- 视频删除
- 响应式基础布局

### M2 — 体验增强

- 播放速度调节
- 搜索与排序
- 视图切换（网格/列表）

### M3 — 进阶功能

- 非 MP4 格式实时转码播放
- 性能优化
